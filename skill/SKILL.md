# 麦麦暗号厨房

菜单上不存在的搭配，这里全都有。

## 何时使用

- 「麦当劳套餐里薯条能换成什么」
- 「给我配一个热量最低的组合」
- 「有没有便宜又好吃的搭配」
- 「来个隐藏菜单 / 暗号菜单」
- 「我想吃点不一样的」

## 工作流

1. 调 `query-nearby-stores` 确定门店，再调 `query-meals` 取套餐列表（取前 8 个，控调用次数）。
2. 对每个套餐调 `query-meal-detail`，解析出 `groups`：每组的 `default`（默认项）与 `options`（可替换项，含加价与热量）。
3. 对各组选项做笛卡尔积枚举，**跳过全默认组合**（那是原版套餐，不是隐藏菜单）。
4. 计算每个组合的 `price = 基础价 + Σ加价`、`kcal = Σ热量`。
5. 按规则打暗号标签，排序输出：精选暗号 / 最便宜 / 最轻。

## 暗号规则

| 暗号 | 触发条件 | 一句话 |
|---|---|---|
| 白嫖暗号 | 差价 = 0 | 一分钱不多花，但换了个搭配 |
| 大改暗号 | 替换项 ≥ 2 处 | 改得亲妈都不认识 |
| 微调暗号 | 只替换 1 处 | 只动一处，稳中求变 |
| 提神暗号 | 含咖啡 / 拿铁 / 美式 | 咖啡因到位 |
| 肉食暗号 | 含鸡 / 牛 / 腿 / 翅 / 肉 | 蛋白质拉满 |
| 甜品暗号 | 含派 / 甜筒 / 麦旋风 / 冰 / 芋 | 糖分优先 |
| 轻断食暗号 | 有热量数据且 ≤ 150 kcal | 热量压到最低，吃完没有负罪感 |

## 输出格式

```
[轻断食暗号] 热量压到最低，吃完没有负罪感
    板烧鸡腿堡套餐 · 玉米杯 + 无糖可乐  |  26 元  |  70 kcal
     换: 中薯条 -> 玉米杯
     换: 中可乐 -> 无糖可乐
```

## 注意事项

- **绝不自动下单**。本项目只做组合与推荐，下单需用户另行确认。
- 单次对话的 MCP 调用控制在 10 次以内（套餐详情最多取 8 个），避免触发 600 次/分钟限流。
- 不同门店菜单与供应状态不同，输出以官方实时结果为准。
- Token 只从环境变量 `MCD_MCP_TOKEN` 读取，不要写进任何文件。
